# Tiago Dantas, PhD

I build and evaluate machine learning models to forecast demand, predict customer behavior, and detect anomalies. My work combines statistical research with practical ML and reproducible evaluation.

Here I share research implementations, reusable tools, and experiments that make model performance and limitations easier to understand.

## Selected work

### [baggets](https://github.com/tiagomendesdantas/baggets)

A Python library for bootstrap forecasting ensembles, with pluggable selection strategies and optional PyTorch N-BEATS models. It connects my published forecasting research with experiments in ensemble selection and statistical versus neural models.

The validation reports document comparisons with the original R implementation, differences from the published results, and the limitations of the neural experiments.

[Code and usage](https://github.com/tiagomendesdantas/baggets) · [Validation report](https://github.com/tiagomendesdantas/baggets/blob/main/reports/validation_report.md) · [Neural comparison](https://github.com/tiagomendesdantas/baggets/blob/main/reports/m8_nbeats.md)

### [Bagged.Cluster.ETS](https://github.com/tiagomendesdantas/Bagged.Cluster.ETS)

The original R implementation of the forecasting method I developed with Fernando Cyrino Oliveira, combining bootstrap aggregation, clustering, and exponential smoothing. The method was published in the *International Journal of Forecasting* in 2018.

[Paper](https://doi.org/10.1016/j.ijforecast.2018.05.006) · [R implementation](https://github.com/tiagomendesdantas/Bagged.Cluster.ETS) · [Related R package: tshacks](https://github.com/tiagomendesdantas/tshacks)

### [Rspotify](https://github.com/tiagomendesdantas/Rspotify)

An earlier R package for accessing Spotify's API, with examples exploring artist networks and audio features. Retained as part of my open-source history; compatibility with the current API has not been verified.
